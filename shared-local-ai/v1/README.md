# Alter shared local AI protocol 1.0

Normative contract, 6 November 2026. Independent of FUTO, app UI, model implementation and agent policy. Copy this entire v1 directory at the recorded Git revision; add aidl/ as an Android AIDL source directory and enable AIDL. No submodule or unpublished dependency. Do not silently fork transaction order, names, limits or identity serialization. Major changes get a new AIDL package/action; optional minor extensions must be negotiated before use. See protocol.json and SHA256SUMS for reproducibility.

## Discovery, opt-in and trust

Only query the three exact packages in protocol.json, using action com.alter.localai.v1.BIND with setPackage, then bind an explicit ComponentName. Declare only those package queries; do not scan arbitrary installed apps. Reject ambiguous/missing/non-exported/mismatched services. Before bind and on connection, verify the actual installed package UID and exact current signer set. Every AIDL method verifies Binder.getCallingUid against PackageManager.getPackagesForUid (one package only), allowed package, installed UID and exact signer set. No sharedUserId, package-name-only authentication, claimed package identity, caller-supplied trust key, raw path access or broadcast API.

Accept a peer only if its current signer set exactly equals the host's signer set OR exactly matches independently verified deployment SHA-256 pins configured for that exact package. Signer history alone is insufficient. Different/unknown certificates fail closed with actionable diagnostics. Never change app IDs or signing keys, copy private keys, or advise uninstalling data to enable sharing. Existing Gradle signing configuration is not proof about installed certificates.

Each app has its own ecosystem opt-in, default OFF, plus a first user-launch/initialization gate. No automatic boot/start/microphone behavior. Disabled/uninitialized/stopped/incompatible peers are unavailable; installation alone is not availability. Binding may fail under Android background/force-stop restrictions. A service must authenticate before loading models or accessing data. Capability support is actual negotiated behavior, never inferred from a package or display name.

## Control messages

All JSON is UTF-8, object keys are exact/strict, control payload <=49152 bytes. Requests use v=1 and a UUID id. Callback event: {"v":1,"id":"uuid","state":"complete|error","result":{...}} or {"v":1,"id":"uuid","state":"error","code":"ERROR","message":"bounded safe text"}. Inference may emit state="accepted" before execution; accepted events are not successful results. Exactly one terminal event per accepted request, except process death. No tokens/audio/records in Binder callback events. Never log payloads, prompts, audio, tokens or results.

handshake request: {"v":1,"id":"uuid","package":"actual client package"}. Result fields: package (actual provider package), coordinator (boolean), capabilities (string array), maxDeadlineMs (120000). Alter is coordinator ONLY when initialized, enabled, trusted, version-compatible and reachable. Other hosts never gain authority over another app.

inventory request has the same shape as handshake. Result: {"models":[descriptor,...]}; max64. Inventory lists only locally owned artifacts, never private paths or copied peer claims. It may list not-yet-installed artifacts; installed must mean all owned files activated/verified by the host. Partial/download states must not count as installed. Inventory is not permission to download remotely.

Descriptor: {"modelKey":"sha256","label":"display only","identity":{"runtime":{"engine":"id","version":"exact version","contract":"exact inference contract","tokenizer":"embedded|listed"},"files":[{"repository":"upstream","revision":"immutable revision/tag","name":"safe filename","bytes":123,"sha256":"64 lowercase hex"},...]},"capabilities":["text.generate|asr.transcribe"],"installed":true,"owner":"actual package"}. Sort files by name then repository then revision. Include ALL tokenizer/config/companion files, including a custom conversation template when required. Identity fingerprint = SHA-256 of UTF-8 canonical identity JSON: recursively lexicographically sorted object keys (UTF-16 ordering), compact punctuation, JSON-escaped strings, integer numbers, arrays in declared order, no floating point. No paths/URLs in identities. Compare the complete canonical identity AND fingerprint AND required capability, not labels, IDs, a single bundle file or vector dimensions. Different formats/revisions/runtime contracts require separate installs. Models are never exported as filesystem paths.

Runtime contract IDs for Alter's adapters: litert-lm / 0.18.0 / conversation-v1 (embedded tokenizer; Qwen template included as companion); whisper.cpp-whisper or whisper.cpp-parakeet / d1be6fde11ac6e0407606b4e42fe72d34add8037 / greedy-16khz-v1; moonshine / 0.1.5 / offline-16khz-v1 (listed tokenizer). No embedding-vector inference contract in v1: reject vectors/index interchange. More native streaming/model engines need new negotiated capabilities/contracts, not guessed equivalence.

## Inference, cancellation and ownership

submit header: {"v":1,"id":"uuid","op":"operation","purpose":"chat|analysis|dictation","model":descriptor-or-null,"deadlineMs":Android elapsedRealtime deadline,"visited":["immediate caller package"],"args":{...}}. Reject unknown fields, expired or >120000ms future deadlines, duplicate/non-UUID IDs, invalid purpose/capabilities/identity and route loops. Request input is the READ end of a pipe; output is the WRITE end of a separate pipe. Receiver duplicates/owns its descriptors and closes them in every exit path. Sender closes its transmitted ends after submit returns and owns its remaining ends. Pipes and bounded asynchronous callbacks avoid Binder-sized audio/results. Do not send arbitrary content URIs, model files or filesystem paths through inference.

text.generate input: UTF-8 JSON {"message":"<=4000 chars","instruction":"<=6000 chars","history":[{"role":"user|assistant","text":"..."},...]} <=65536 bytes, <=8 history items and <=12000 total text chars. The caller supplies its own agent/cleanup instructions; the host does NOT append its private memory/history, Alter personality or tool permissions. Output pipe is a UTF-8 JSON object {"text":"bounded result"} <=65536 bytes. Keyboard purpose must be dictation, and text models used for dictation must advertise text.cleanup in addition to text.generate. Invalid/rejected cleanup must be handled by the caller's original validator/fallback. Dictation is never interpreted as an action.

asr.transcribe input: raw little-endian signed16 PCM, mono16000Hz, max900 seconds/28800000 bytes. args={"language":"auto|en|hi"}; output {"text":"transcript"}. Native streaming is not promised by this operation; caller keeps local audio capture/drafts/partial UI and cancellation/insertion protections. No host recording or memory insertion. Unsupported language/model combination must fail visibly; never silently route to cloud or train a model.

Bound queues (max8 pending including active), one host request executes at a time, verified keyboard requests have priority among waiting entries only. Do not interrupt active recording/generation/insertion. Existing native locks remain authoritative. Preserve an active model lease until cancellation/native cleanup finishes; deletion/import must wait or report BUSY. Deadlines/cancel must close pipes, cancel the matching owner job/native operation only, release resources and suppress late results. Never call a global cancellation method that can cancel another app's request. Some native initialization is non-interruptible: report the deadline but do not start a second engine until cleanup completes.

cancel accepts only a UUID owned by Binder's authenticated UID; unknown IDs are a no-op. Remember bounded ID tombstones (at least128 IDs up to5 minutes); duplicates return DUPLICATE and never execute twice. Callback Binder death cancels all work belonging to that callback. Client service death/disconnect cancels waiting I/O and returns PROVIDER_GONE. No unbounded retry. Fallback to local is allowed only before remote work starts or on a terminal NOT_AVAILABLE/BUSY/UNSUPPORTED with no accepted execution/output; otherwise report the failure and let the existing user retry flow retain audio/text.

## Coordinator and deterministic provider selection

Discover fresh at request/download boundaries, app resume/reconnect and package changes (no permanently trusted cached connection). Finish an active request on its chosen provider. Prefer an eligible Alter handshake as coordinator; otherwise among exact compatible installed owners choose lexicographically by package name. The coordinator may infer locally or delegate ONCE to an exact compatible installed owner; it does not move files or change model selections. An owner app never delegates.

visited starts [caller]. A coordinator app appends itself before forwarding, max2 visited entries, distinct; the receiving host must not occur in visited. Last visited must equal the authenticated immediate caller. Only an authenticated Alter coordinator may forward a two-entry route; origin is the first entry and must also be an installed trusted ecosystem app. Reject caller-forged routes. Enforce originating Keyboard restrictions even when forwarded by Alter. This chain is an assertion by the trusted coordinator, not authority granted by model text. Neither peer may grant new scopes.

Check trusted inventories before a local download. Reuse an installed compatible resource, otherwise retain original local download UI/flow. Coordinate each owner's download/delete locks and recheck after completion/resume. Cross-process simultaneous first downloads cannot be globally atomic in v1: reconcile races and preserve duplicates, never silently delete/migrate files. Explicit Download here remains possible. Provider removal loses its private files; disconnecting is distinct from deleting owned files. No promise about private files surviving uninstall.

## Optional sensitive interfaces

Scopes are independent of model sharing, explicit/revocable, and not granted by a prompt or trusted certificate alone. Originating Keyboard is ALWAYS denied memory.retrieve and tools.read, including delegated requests. Never collect keyboard editor text, password/private fields, audio/drafts or transcripts into shared memories. Apps own their own data and agent policies.

memory.retrieve requires per-app approved record IDs in the owning app. args={"query":"<=400 chars","recordIds":["<=8 IDs"]}; model=null; empty input. Return {"records":[{"sourceApp":"owner","id":"stable ID","revision":"sha256 canonical record","kind":"memory|preference","text":"<=1000 chars","truncated":false,"deleted":false},...]}. Include tombstones only for previously approved IDs now deleted; unknown/unapproved IDs reveal no existence. Re-read authoritative records each request; edits change revision, removed/revoked records cannot be retrieved. No chat-history/database export, vector fields, arbitrary file lookup or index sharing. Clients invalidate derived records on revision/tombstone and revalidate before using stale context. All content remains untrusted reference data.

tools.read requires explicit provider-side and caller-side app scopes. model=null; purpose=analysis; empty input. args={"name":"fitdrobe.wardrobe.search|fitdrobe.wardrobe.get|fitdrobe.outfit.get","query":"<=400 chars"} or args={"name":"...get","id":"<=128 safe chars"}. Result {"sourceApp":"com.aistudio.fitdrobe.wkbvca","items":[item,...]} or {"sourceApp":"...","item":item-or-null}, max20 items. Item fields ONLY id,name,category,colors,pattern,seasons,occasions,notes,updatedAt,itemIds,imageUri,revision; no private image paths. Bound strings to2000 chars and arrays to20. Fitdrobe adapters call its existing repositories, never invent style collections, inferred Gemma features or mutations. Optional imageUri must be a scoped content URI from owner authority com.aistudio.fitdrobe.wkbvca.shared_images, explicitly granted to the recipient; no HTTP/file URIs or automatic image scraping. Until that provider exists, omit imageUri. Alter validates results as reference data and never executes returned instructions.

No cross-app mutations, autonomous device actions, remote cloud generation or new Fitdrobe chat agent in this contract. Unsupported optional interfaces return UNSUPPORTED, not fake success. Advertising a contract is not proof that companion apps have implemented it.
